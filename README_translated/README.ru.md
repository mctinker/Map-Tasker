# MapTasker

> Этот перевод создан автоматически. В случае каких-либо расхождений, приоритет имеет [оригинальный README на английском языке](../README.md).

## Просматривайте, редактируйте и анализируйте Project, Profile, Task и Scene приложения Tasker в браузере вашего настольного компьютера (Mac/Windows 11/Linux) на основе резервной копии Tasker или экспортированного XML-файла

[[Больше примеров]](<https://github.com/mctinker/Map-Tasker/wiki#sample-output>)

Это приложение, дополняющее [Tasker](https://tasker.joaoapps.com/), предназначенное для работы в веб-браузере (см. [примечание 1](#1)).

Я обнаружил, что мои Tasker Project/Profile/Task/Scene становятся неуправляемыми, а экран телефона слишком мал для удобной навигации по ним. Поэтому я написал программу на Python, которая создаёт полную карту всей моей конфигурации в веб-браузере на основе XML-файла резервной копии Tasker, сохранённого на жёстком диске моего настольного компьютера.

Со временем я усовершенствовал эту карту, добавив множество дополнительных опций, включая возможность редактировать объекты Tasker и получать углублённый анализ конфигурации Tasker.

Резервную копию Tasker или другой экспортированный Tasker XML-файл можно либо загрузить вручную на свой ПК/Mac/Linux/облачный диск, либо эта программа может получить его напрямую с вашего Android-устройства (см. [примечание 2](#2)).

## Возможности

- Выбирайте уровень детализации вывода — от общего обзора до очень подробного уровня вашей конфигурации.
- Отображайте только один Project, Profile или Task.
- Включайте/исключайте условия Profile и Task: States, Events и т. д.
- Просто выводите всё потоком, или сделайте вывод "аккуратным", выровняв все поля.
- Измените внешний вид: выберите 'светлый' или 'тёмный' режим.
- Выводите данные с помощью выбранного вами моноширинного шрифта и выделяйте имена Project, Profile и Task курсивом, полужирным, подсветкой и/или подчёркиванием.
- Изменяйте цвета, связанные с различными аспектами вывода, в зависимости от настроения.
- Включайте описания TaskerNet и/или настройки Tasker (preferences).
- Для сложных конфигураций можно по желанию включить справочник гиперссылок на ваши Project, Profile, Task и Scene.
- Отображайте диаграмму всей вашей конфигурации Tasker, а также Task Flow.
- Интерфейс командной строки или графический интерфейс.
- Используйте экспортированный XML или получайте XML напрямую с вашего Android-устройства для построения карты конфигурации.
- Отправляйте Project, Profile, Task и Scene обратно в Tasker на вашем Android-устройстве.
- Сохраняйте и восстанавливайте настройки времени выполнения.
- Выявляйте Task с чрезмерным количеством "actions", которые потенциально следует разбить на несколько Task.
- Опция анализа с помощью ИИ для анализа конкретного Project, Profile, Task или Scene с использованием либо серверных моделей ChatGPT/Claude/Gemini, либо локальных моделей Llama (через Ollama).
- Отображайте результаты непосредственно в графическом интерфейсе: (конфигурации) Map View, Tree View и Diagram View.
- Автоматическое обнаружение обновлений и возможность установки новых версий.
- Расширенный поиск и структурированная функция 'Find/Replace'.
- Добавляйте и редактируйте Project, Profile, Task и Scene (см. [примечание 6](#6)).
- Просматривайте список изменений начиная с определённой даты.
- Привязывайте Project, Profile, Task или Scene к публикации TaskerNet, из которой они взяты, получайте уведомление, когда автор публикует новую версию, и принимайте его изменения по одному.
- Анализируйте состояние Tasker XML, а также многочисленные переменные во всей конфигурации.
- Сравнивайте XML-файл с загруженным XML.

## Зависимости программы

### - Python версии 3.11 или новее

### - Полный или частичный XML-файл Tasker: backup.xml или другой экспортированный Tasker XML-файл

&nbsp;&nbsp;&nbsp;Вам будет предложено найти и указать экспортированный XML-файл Tasker (например, backup.xml) на вашем рабочем столе, созданный Tasker версии 5 или версии 6. При желании вы можете получить его напрямую с вашего Android-устройства (см. [примечание 2](#2)).

### - Анализ с помощью ИИ

&nbsp;&nbsp;&nbsp;Для этого требуется действительный API-ключ при использовании серверного анализа и/или установка Ollama для локального анализа (см. [примечание 3](#3)).


## Установка

Эта программа и все её необходимые компоненты займут около 230 МБ места. Рекомендуется устанавливать её в виртуальное окружение (вариант 2).

- Установите MapTasker, введя одну из следующих команд в Терминал/Командную строку:

     ```python -m pip install maptasker -U```
                 ...ИЛИ...
     ```uv add maptasker```

- Чтобы установить его в виртуальное окружение, введите следующую команду в Терминал/командную строку:

  через pip...
  - `cd xxx`, где 'xxx' — это каталог, в котором вы хотите настроить виртуальное окружение.
  - `python -m venv venv`
  - Активируйте виртуальное окружение...
    MAC/Linux: `source {directory path to 'xxx'}/venv/bin/activate`
    Windows: `venv\Scripts\activate`
  - `pip install maptasker`

  ...или...
  
  через uv...
  - `cd xxx`, где 'xxx' — это каталог, в котором вы хотите настроить виртуальное окружение.
  - `uv venv`
  - Активируйте виртуальное окружение...
    MAC/Linux: `source {directory path to 'xxx'}/venv/bin/activate`
    Windows: `venv\Scripts\activate`
  - `uv pip install maptasker`

- Функции анализа с помощью ИИ требуют дополнительных библиотек (OpenAI, Anthropic, Google и Ollama). MapTasker не устанавливает их автоматически; если они вам нужны, установите MapTasker с дополнением `ai`:

     ```python -m pip install "maptasker[ai]" -U```
                 ...ИЛИ...
     ```uv add "maptasker[ai]"```

### Отчёты из командной строки

Health Check, Compare, Changes Since, Export и наблюдение за папкой (watch) выполняются без окна, что позволяет автоматически проверять ночную резервную копию Tasker (из `cron`, Планировщика заданий, `launchd` или задания CI):

```
maptasker -healthcheck -file backup.xml                 # проблемы в резервной копии
maptasker -compare older.xml newer.xml                  # различия между двумя резервными копиями
maptasker -changes_since week -file backup.xml          # что изменилось: today (сегодня), week (неделя), month (месяц), all (всё), определённая дата, или 3d (3 дня)
maptasker -export map -format md -file backup.xml       # Map (или диаграмму) в формате md, json или pdf
maptasker -watch ~/TaskerBackups                        # записывает каждую новую резервную копию в историю
```

- **`-file`** принимает резервную копию или папку (используется самый новый `.xml`-файл в ней). `-outdir` выбирает, куда записывать файлы, а `-save` также сохраняет отчёт в виде файла, как это делает окно.
- **Только отчёт, и исключительно отчёт, идёт в стандартный вывод (standard output)**; всё остальное идёт в стандартный поток ошибок, поэтому `maptasker -healthcheck -file backup.xml > report.txt` даёт чистый отчёт.
- **Коды выхода (Exit codes)** позволяют сценарию действовать в зависимости от результата:

  | Код | Значение |
  |---|---|
  | 0 | Готово, и не было ничего, о чём нужно сообщать |
  | 10 | Отчёт обнаружил что-то: ошибки Health Check (`-fail_on warning`, чтобы включить предупреждения, `-fail_on never`, чтобы их игнорировать), или различия |
  | 11 | У `-changes_since` не было более ранней конфигурации для сравнения (первый запуск начинает историю) |
  | 1 | Ошибка программы |
  | 2 | Не удалось записать файл (включая папку `-outdir`, которую невозможно использовать), или не удалось создать вывод |
  | 3 | Файл не является действительной резервной копией Tasker |
  | 5 | Запрошенный отдельный Project, Profile или Task (`-project`, `-profile` или `-task`) не найден |
  | 6 | Файл не был указан, или файл/папка не существует |
  | 7 | Недопустимая опция, например неверный цвет, неизвестное значение `-fail_on`, или сравнение файла с самим собой |
  | 8 | Запрос к Android-устройству, на котором запущен сервер Tasker, не удался |

- **История.** Каждая загруженная резервная копия записывается в историю конфигурации, которую читает `-changes_since`. `-watch FOLDER` записывает каждую новую, полную резервную копию, появляющуюся в `FOLDER`, с датой по файлу, так что история заполняется даже в те дни, когда вы никогда не открываете MapTasker; `-watch FOLDER -once` проверяет только один раз, для запланированного задания. История хранится в папке `MapTasker_Timeline` в каталоге, из которого запускается MapTasker, поэтому запланированное задание должно использовать `-history_dir`, чтобы указывать на ту же папку, которую использует окно.
- **Больше ничего не меняется.** Эти запуски никогда не открывают браузер и никогда не перезаписывают настройки, которые сохраняет окно.

## Устранение неполадок и часто задаваемые вопросы

**В: Диаграмма `MapTasker_Map.txt` отображается со смещённым выравниванием в Блокноте (Notepad) Windows.**

О: Блокнот может неправильно обрабатывать интервалы в этом файле.

Рекомендуется использовать другой текстовый редактор, например Notepad++, VS Code или Typepad (и установить его по умолчанию для файлов `.txt`). Убедитесь, что 'перенос текста' отключён и используется моноширинный шрифт.

**В: Как получить XML-файл Tasker напрямую с моего Android-устройства?**

О: Необходимые условия:

1- Браузер и Android-устройство должны быть в одной локальной сети.

2- На Android-устройстве должен быть установлен и активен [проект Tasker 'Http Server Example'](https://shorturl.at/bwCD4), а сервер должен быть запущен.

Дополнительные сведения доступны в разделе "Примечания" этого README.

**В: Соединители диаграммы смещены для имён на китайском, корейском или японском языке.**

О: Это известная проблема, связанная с метриками шрифтов для этих языков в библиотеке построения диаграмм.

**В: Почему некоторые actions Task и states/events Profile недоступны для редактирования/добавления?

О: В некоторых случаях для этих actions, events или states требуется информация, доступная только на Android и/или внутри самого Tasker. Разрешение редактирования таких данных привело бы к неполному Task или Profile, что вызвало бы сбой Tasker.

## Примечания

Детали некоторых пунктов, упомянутых в разделе "Устранение неполадок и часто задаваемые вопросы", сохранены здесь для дополнительного контекста.

### 1
**Особенности Windows 11:**

- Поддерживается только Windows 11. Более ранние версии Windows не поддерживаются.
- При проблемах с отображением `MapTasker_Map.txt` в Блокноте используйте альтернативный текстовый редактор, например Typepad, и установите его по умолчанию для файлов `.txt`.

### 2
**Прямое получение XML с Android:**

Чтобы получить XML-файл Tasker напрямую:

- Убедитесь, что настольный компьютер и Android-устройство находятся в одной локальной сети, и что Tasker запущен.
- На Android-устройстве должен быть установлен и активен [проект Tasker 'Http Server Example'](https://shorturl.at/bwCD4), а сервер должен быть запущен. Не забудьте выполнить Task "Update GD HTTP Info" и (только при первом использовании) ввести идентификатор Google Drive, когда вас об этом попросят.
- После получения XML сохраняется на вашем рабочем столе, и его не нужно постоянно получать повторно, если он не изменился.

### 3
**Поддержка ИИ**

Анализ с помощью ИИ доступен только через графический интерфейс. Вы можете выполнять анализ, используя только один Project, Profile, Task или Scene. Поддержка доступна для серверных моделей OpenAi (ChatGPT), Gemini и Anthropic, а также для локально работающих моделей Llama.

Модели на основе Llama поддерживаются через [Ollama](https://ollama.com/), которую вам нужно скачать, установить и запустить вручную один раз, чтобы настроить сервер на вашем рабочем столе. MapTasker динамически загрузит модели Llama за вас, если они ещё не загружены.

Вспомогательные модули ИИ не устанавливаются по умолчанию при установке MapTasker. Вместо этого они устанавливаются динамически при первом использовании конкретного запроса к ИИ. Таким образом, если вы не планируете использовать ИИ, вы не понесёте эти дополнительные затраты.

## Заявление о конфиденциальности

Никакая информация вообще не собирается и не отправляется по сети мне или любой третьей стороне, кроме перечисленного ниже (сетевой трафик).

При сообщении об ошибке вас, скорее всего, попросят предоставить файл журнала вывода ошибки и ваш XML-файл, оба из которых используются исключительно для отладки программы, а затем немедленно удаляются.

Сетевой трафик следующий:

- Локальный трафик LAN при получении XML напрямую с вашего Android-устройства.
- При запуске один раз в день производится проверка на pypi.com, доступна ли новая версия.
- Программа обновляется с pypi.com (через 'pip'), если в графическом интерфейсе выбрано 'Upgrade'.
- Файл 'Changelog.md' считывается с '<https://github.com/mctinker/Map-Tasker>', если в графическом интерфейсе выбрано "What's New".
- chatgpt.com используется при использовании анализа ИИ с любой из моделей OpenAi. Вывод MapTasker отправляется на сервер через стандартный вызов API для анализа. То же самое касается Claude (Anthropic) и Gemini (Google).
- Новые и обновлённые локальные модели ИИ будут загружаться с '<https://ollama.com/library>' при запуске функции анализа ИИ.
- Гиперссылки на источники изображений и видео, определённые с помощью HTML-тега '<img src=https://...>' в метках actions Task и описаниях TaskerNet, будут открываться при нажатии на них. Примеры: imggur.com, Youtube, Dropbox, Google Drive и т. д.

## Содействие проекту

Вклад приветствуется! Вот несколько способов внести свой вклад в MapTasker:

**Сообщение об ошибках:**

- Если вы нашли ошибку, пожалуйста, откройте issue на [странице GitHub Issues](https://github.com/mctinker/Map-Tasker/issues).
- Включите как можно больше деталей:
  - Шаги для воспроизведения ошибки.
  - Ожидаемое поведение и фактическое поведение.
  - Вашу операционную систему и версию Python.
  - Версию MapTasker.
  - Соответствующие части вашего XML-файла Tasker (если применимо, и убедитесь, что не включена никакая конфиденциальная информация).
  - Файл `maptasker.log`, если он был создан с опцией `-debug`.

**Предложение улучшений:**

- Откройте issue на GitHub, описывая ваше предложение.
- Объясните сценарий использования и почему это улучшение будет полезным.

**Pull Request'ы:**

- Если вы хотите внести вклад в код:
    1. Сделайте fork репозитория.
    2. Создайте новую branch для вашей функции или исправления ошибки (например, `feature/new-output-format` или `fix/xml-parsing-error`).
    3. Внесите свои изменения.
    4. Убедитесь, что ваш код соответствует стилю кода Black (как указано на значке).
    5. Добавьте тесты для ваших изменений в директорию `tests/`, если применимо.
    6. Убедитесь, что все тесты проходят.
    7. Отправьте pull request в branch `Master`.

**Стиль кода:**

- Этот проект использует [Ruff](https://docs.astral.sh/ruff/formatter/) для форматирования кода. Пожалуйста, убедитесь, что ваш вклад отформатирован с помощью Ruff.

Мы благодарны за вашу помощь в улучшении MapTasker!

## Известные проблемы

- Соединители диаграммы смещены, если имена на китайском, корейском или японском языке.
- Не все actions Task и редактирование states/events Profile поддерживаются, так как некоторые требуют информации, доступной только на Android-устройстве.
